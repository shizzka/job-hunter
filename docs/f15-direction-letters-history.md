# F15 — письма и история направлений

В одном профиле и аккаунте hh можно искать работу по разным профессиям.
У каждого направления своё запасное письмо и своя история решений.

## Что видит владелец

«Что ищу» → выбранное направление → «Изменить» → «Запасное письмо»:
просмотр, новый текст и удаление письма. До 1500 символов; переводы строк
разрешены, недопустимые управляющие символы отклоняются. Изменение сохраняется
вместе с направлением, отмена ничего не меняет.

Если своего письма нет, можно открыть «Посмотреть прежнее письмо». Бот показывает
текст из старого файла профиля, название направления и вопрос
«Использовать это письмо для направления …?». Только явный выбор добавляет его
в черновик, затем требуется сохранение. Бот не угадывает профессию и не переносит
письмо автоматически. Исходный файл остаётся на месте. Пока своего письма нет,
используется прежний нейтральный текст. Необязательное предложение письма от ИИ
не добавлено.

Отправка проверяет выбранное резюме, направление и точный текст подготовленного
письма. Подмена письма, чужое резюме, устаревшее направление или принадлежность
одного резюме нескольким направлениям останавливают отправку. Проверка повторяется
непосредственно перед обращением к отправителю. Правила проверки фактов в обычных
письмах сохранены.

## Обзор путей

| Путь / экран | Было | Теперь / решение |
|---|---|---|
| «На рассмотрении» | F14 уже выбирает активное направление | Сохранено; также читается записанное направление карточек, созданных до оценки, когда поисковый запрос общий для нескольких профессий |
| «Отклики HH» | F14 уже разделяет сведения об откликах по резюме | Сохранено |
| Анкеты и списки чатов | F14 уже разделяет списки, B22 проверяет принадлежность чата по резюме отклика | Сохранено; новый журнал также записывает эту принадлежность |
| «Статистика» | Общая история профиля | Активное направление в заголовке; его решения, отклики и прогоны. Администратор сохраняет отдельные блоки профилей |
| «Дайджест» | Общая история профиля | Только выбранное направление, в том числе при отправке после поиска |
| «Отказы и конверсии» | Связь только по вакансии | Направление входит в связь отклика и последующего ответа, включая одинаковые номера вакансий |
| «Прогоны» | Последние записи профиля | Последние прогоны выбранного направления; чужие запуски не вытесняют его последний |
| «Последний запуск» | Последний запуск профиля | Последний / указанный запуск в выбранном направлении; чужой номер не открывает чужой запуск |
| «Почему нет откликов», ежедневная сводка, отчёты в командной строке | Общие сведения профиля | Используют выбранное направление |
| «Лог чатов» | Общий текстовый журнал процесса | Записи журнала чатов по принадлежности B22. При отсутствии таких записей старые строки сопоставляются только по явному номеру чата |
| «Сброс просмотренных» | Все пропуски профиля за период | Только выбранное направление и период, включая сохранённые оценки. Подтверждение связано с профилем и направлением; старая кнопка после переключения не действует |
| `direction_stats.py`, выгрузка резюме | Уже группирует наблюдения hh по однозначному числовому номеру резюме | Расчёт сохранён; экран и выгрузка по умолчанию выбирают направление. Неоднозначные наблюдения вынесены отдельно; несколько резюме одной вакансии не доказывают ошибочную отправку |
| Решения, оценки, карточки, отзывы | Направление / резюме присутствовали не везде | Новые записи несут направление, hash и числовой номер резюме, если он известен. Отзыв сохраняет принадлежность карточки после переключения направления |
| `seen.py` | Один вердикт на вакансию во всём профиле | Пропуски и ручные решения разделены по направлениям. Полная история сохраняется для переноса в аналитику |
| Сохранённые оценки | Ключ уже включал направление | Дополнительно включает выбранное резюме и версию его текста; устаревшие оценки не заменяют новую оценку |
| Очередь отложенной оценки | Общая очередь профиля | Отдельная очередь направления; старые записи с однозначной принадлежностью подхватываются, неизвестные сохраняются без назначения |
| Старый механизм повторных откликов | Общая история попыток | Новые попытки разделены по направлениям и содержат резюме. Чтение для дополнения аналитики включает старый файл и все новые файлы направлений |
| Дополнение аналитики | Могло приписать импорт текущему направлению | Читает все исходные записи, восстанавливает принадлежность из сохранённых сведений, не использует текущий выбор как доказательство. Повторный импорт не дублирует запись |

На экранах истории есть «Это направление», «Все направления» и
«Направление не указано». В общем представлении сводок решения дополнительно
показаны по направлениям. У прогонов и записей чата видна принадлежность.
Кнопки сохраняют обычную клавиатуру раздела. Выгрузка всех направлений:
`/direction_csv all`.

## Старые записи

Общий способ определения принадлежности находится в `direction_history.py`.
Используются сохранённые направление, номер / hash резюме, версия текста либо
поисковый запрос, соответствующий ровно одному направлению. Противоречивые
или неоднозначные сведения не считаются подтверждением. Название вакансии,
название профессии и текущий выбор не используются для угадывания.

При однозначной связи с запуском / откликом можно восстановить принадлежность
событий того же запуска / ответа работодателя. Для наблюдений hh сведения
о резюме из сохранённого отклика имеют приоритет. Источники вакансий разделены.
Неизвестные записи доступны в отдельной группе, без изменения исходных файлов.
У профиля с одним направлением сохраняются прежние числа для записей с
установленной принадлежностью; необъяснимые старые записи тоже остаются отдельно.
Если направление ещё не выбрано и оно единственное, экраны открывают его.

## Что остаётся общим

- Вход в hh, ограничения частоты, суточный предел и остановка после ограничений
  hh: переключение профессии не должно обходить ограничения аккаунта.
- Подтверждённые отклики, уже существующие отклики, неопределённый результат
  отправки и запрет автоматического повтора: они останавливают повтор для той же
  вакансии в аккаунте, но учитываются в истории своего направления.
- Исходные сведения hh о переговорах и чатах собираются для аккаунта целиком;
  чтение экранов разделяет их по резюме. Дополнение аналитики тоже читает весь
  аккаунт и сохраняет принадлежность каждой записи.
- Состояние работающих процессов, диагностика и исходный журнал поиска
  `/raw_log`: они описывают работу профиля, а не результаты одной профессии.
- Общие факты кандидата и список нежелательных компаний остаются прежними.

## Проверки

Новые синтетические сценарии: `test_direction_letters.py`,
`test_direction_history.py`. Две профессии используют один аккаунт и одинаковые
номера вакансий. Проверяются выбор и сохранение старого письма, отмена и устаревшие
кнопки, проверка письма при отправке, раздельные экраны, старые записи,
сохранённые оценки и пропуски, перенос отзывов и история одного направления.

Связанные проверки включают F14/B22, обычные письма и проверку фактов, аналитику,
повторные отклики, меню Telegram и офлайн-прохождение отправки в Chromium.
В браузерной проверке все ответы обслуживаются локальными подменами; реальных
запросов к hh нет. Полный набор тестов оставлен отдельному работнику.

Расширенный прогон связанных файлов: **1038 passed**. После уточнений
восстановления принадлежности повторены **213 passed**; письмо, выбор резюме,
ручной отклик и браузерный путь — **60 passed**. Эти числа относятся к отдельным
прогонам, а не к сумме уникальных тестов. Последнее уточнение карточек до оценки
проверено вместе с историей, F14 и отправкой: **57 passed**.

Все команды использовали `/mnt/work/job-hunter/venv/bin/python -m pytest -q
-p no:cacheprovider` и явные имена связанных файлов. Финальная проверка истории:

```bash
/mnt/work/job-hunter/venv/bin/python -m pytest -q -p no:cacheprovider \
  tests/test_direction_history.py tests/test_telegram_review.py \
  tests/test_direction_runtime.py tests/test_manual_apply_direction.py
```

Один промежуточный прогон проверки изоляции заметил временный файл служебного
состояния Telegram вне рабочего дерева. Источник не установлен; этот файл не
изменялся и не удалялся. Последующие завершённые прогоны, включая расширенный,
такого изменения не обнаружили. Данные профилей не переносились и не исправлялись;
боты не перезапускались.
