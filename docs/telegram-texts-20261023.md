## Решения владельца от 23.10 — выполнено

1. Подтверждено: /dryrun ищет вакансии и не отправляет отклики. Новая кнопка явно сообщает «без откликов»; прежняя клавиатура продолжает работать через алиас.
2. Готовность шагов «С чего начать» берётся из состояния каждого шага, а не из заключительной фразы. Неизвестный режим не считается выбранным. Список резюме показывает до трёх названий, затем «и ещё N», где N = общее количество − показанное. Резюме без названия и одинаковые названия тоже учитываются как отдельные записи.
3. «Обновить тексты» означает повторную загрузку резюме направления с hh.ru. Подпись заменена на «Обновить резюме с hh.ru», действие сохранено.
